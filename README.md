# huijunjin.github.io

Personal homepage of Huijun Jin (Ph.D. candidate, Yonsei University), served by
GitHub Pages as plain static files (`.nojekyll`, no build step).

- `index.html`: home (research, interactive demo, publications, record)
- `cv/`: HTML CV; the PDF is `files/Huijun_Jin_CV.pdf`
- `demo/`: the interactive research demo, one self-contained HTML file
- `assets/`: the shared stylesheet and the script for the hero animation
- `publications/`, `about/`, `resume/`: redirects for the old addresses

To update a publication or a CV entry, edit `index.html` or `cv/index.html`.
